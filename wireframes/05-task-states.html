Task states

A task is a title, a done flag and a place. Every edit is in place; the only popup is the day picker.

A Adding appends to the current list (plan or backlog). Enter adds and stays in the input so several can be typed in a row.

B Editing never opens a form. For a recurring copy the app asks whether the new title applies forward, because PRODUCT.md says title edits change future copies only.

C Reordering is explicit and manual. There is no sort, no "smart" ordering, no drag between focus and plan (use f for that).

D Closing moves a task to Done at the bottom with the time. Focus and Done are states shown by position, not by a coloured badge.

E The day picker covers "move onto today", "move to a day", and "back to backlog" in one card, with typed dates for speed.

F Destructive actions are undoable rather than confirmed. Applies to delete, close, move, and review decisions.

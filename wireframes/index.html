Wireframes for the Omarchy task manager

Structure only: which screens exist, what is on them, and whether the flows make sense. Grey by default; the theme selector at the top right swaps in a real Omarchy theme from colors.toml to check that the structure survives dynamic theming. Numbered dots on each screen match the notes column.

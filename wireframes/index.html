Wireframes for the Omarchy task manager (TUI)

Structure only: which screens exist, what is on them, and whether the flows make sense. The app is a terminal program, so every screen is drawn on a character grid at real sizes: 120×36 for an Omarchy floating terminal (the usual way it is opened), 160×48 for a full tile, 80×44 for a half tile. Grey by default; the theme selector swaps in a real Omarchy theme, mapped the way a terminal would show it. Numbered markers on a screen match the notes column. Each screen is also saved as a .txt file next to its .html.

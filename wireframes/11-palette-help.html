Command palette and help

Two escape hatches so nobody has to memorise the key map before the app is usable.

A The palette is the Omarchy launcher shape: centred card, fuzzy filter, selected row in accent. Actions that apply to the cursor task come first, app-level ones after. Each row shows its direct key, so the palette teaches itself out of use.

B Help is a static overlay of the same keys the hint bar shows, grouped by context. It is the whole map; there are no hidden keys.

Key conventionsLowercase acts on the cursor row. Uppercase reorders or opens schedule editing. Punctuation navigates ([ ] . / : ?). Enter confirms, Escape backs out one level, u undoes the last change.

There is no settings screen. Theme, font and size come from Omarchy; the app has nothing of its own to configure.

Today + backlog (main screen)

  1. Top strip: which day is shown and how to move between days. Right side carries the only global indicators: the review pile count (alert when non-zero), the notes drawer, search, commands, help.
  2. Focus: the few tasks that must get done today. Bold, listed first, always visible. f toggles a task in and out; the list is not capped but the design assumes one to three.
  3. Plan: the ordered working list. Order is manual only (J/K); the app never re-sorts. Row metadata is sparse: where it came from, a reminder chip, a repeat chip.
  4. Done: closed tasks drop to the bottom in the order they were closed, with the time. They stay on the day for history.
  5. Backlog is one flat list; Waiting is the same list filtered under its own heading, so flagged tasks stay visible but out of the way. Due/remind chips are the only per-row extras.
  6. Hint bar changes with the focused pane, lazygit-style. Every action is one key; the mouse works too (click row, drag to reorder) but is never required.
Moving between places t in backlog appends the task to today's plan. b in today sends it back. m opens a day picker. Same task, different place; nothing is copied.

Layout is two panes because the core loop is "look at backlog, pull into today". Both lists visible at once, cursor moves between them with h/l.
